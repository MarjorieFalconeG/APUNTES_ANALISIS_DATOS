

## Sujeto de datos
Persona natural la cual sus datos son procesados 
## Controlador de datos 
Persona fisica y juridica u otro organismoi que determina los fines y medios del procesamiento de datos personales.
## Procesador de datos 
Persona fisica y juridica u otro organismos que procesa datos personales en nombre del controlador 
## Autoridad supervisora 
Entidad supervisora autorizado para hacer cumplir las leyes y regulaciones de proteccion de datos 

# Principios de proteccion de datos 

- Legalidad, equidad y transparencia 
- Limitacion de Proposito 
- Minimizacion de datos 
- Exactitud 
- Limitacion de plazo de conservacion 
- Integridad de confidencialidad

# Pasos para implementar GDPR.

1. Aprobación por la alta gerencia
- Capacitación a gerencia
- Ejecutar una Evaluación GAP
- Aprobación de Project Charter
2. Planificar el proyecto GDPR
- Crear un plan de gestion de proyecto
- Crear un cronograma para la implementaciÓn
3. Roles y responsabilidades
- Definir roles, responsabilidades y autoridad
4. Políticas
- Crear Política de privacidad y protección de datos
- Política de retención de datos
- Capacitar a los empleados
5. Inventario de datos
- Haga un inventario de los datos que maneja
- Enumere sus actividades de procesamiento
6. Gestionar los derechos de interesados
- Establecer una base legal para procesamiento
- Mantener registro de las solicitudes de derecho
7. Evaluacion de impacto de proteccion de datos
- Implementar evaluación EIPD
8. Definir como manejar las violaciones de datos
- Configurar los procesos para identificar y gestionar
violaciones de datos
- Preparase para las notificaciones a la autoridad de
control
9. Transferencias internacionales de datos
personales
- Crear y seguir el procedimiento para transferencias de datos internacionales
10. Garantizar la seguridad de los datos
personales y sensibles
- Implementar las medidas organizativas para
proteger los datos

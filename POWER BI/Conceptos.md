# Tipos de gráficos en Power BI y sus usos prácticos:
- Tarjeta: Mostrar un solo valor clave, como ventas totales o cantidad de clientes.
- Tarjeta de varias filas: Mostrar varios valores clave juntos, como ingresos, costos y beneficios en una misma visualización.
- Gráfico medidor: Medir el progreso hacia un objetivo, como el porcentaje de cumplimiento de una meta de ventas.
- Gráfico KPI: Monitorear un indicador de rendimiento con comparación a valores anteriores, como ventas actuales versus ventas del año pasado.
- Gráficos de barras y columnas: Comparar categorías de datos, como ventas por producto o ingresos por región.
- Gráfico de línea o área: Mostrar tendencias a lo largo del tiempo, como evolución de ventas mensuales o visitas diarias a un sitio web.
- Gráficos combinados: columnas y líneas: Combinar tendencias con comparación de categorías, por ejemplo, ventas por mes con un objetivo anual.
- Gráfico circular o de anillo: Mostrar la distribución de una categoría en porcentaje, como participación de mercado por empresa.
- Diagramas de árbol o Treemap: Visualizar estructuras jerárquicas y contribuciones de cada elemento, como ingresos por línea de producto.
- Árboles de descomposición: Analizar la contribución de distintos factores en una métrica, como desglose de costos operativos.
- Gráfico de embudo: Representar procesos secuenciales y su rendimiento, como el embudo de conversión de clientes.
- Creación de tablas: Presentar datos tabulares de forma estructurada, útil para reportes detallados.
- Matrices de filas y columnas: Mostrar datos en un formato matricial, como ventas por producto y región en una tabla dinámica.
- Minigráficos en tablas y matrices: Agregar minigráficos dentro de tablas para mostrar tendencias sin ocupar mucho espacio.
- Gráfico de cascada: Mostrar cómo una métrica cambia debido a diferentes factores, como ingresos netos afectados por costos y descuentos.
- Gráfico de cintas: Comparar cambios en posiciones de categorías a lo largo del tiempo, útil para ranking de productos o marcas.
- Gráficos de dispersión: Analizar relaciones entre dos variables, como la correlación entre ingresos y gasto en publicidad.
- Mapa geográfico de burbujas: Ubicar datos sobre un mapa con burbujas para representar magnitudes, como ventas por ciudad.
- Mapa geográfico coroplético: Mostrar datos en un mapa con intensidad de color para representar valores, como población por región.
- Mapa geográfico de formas: Visualizar datos en mapas personalizados con formas específicas, como zonas de ventas o regiones geográficas.
- Mapa ArcGIS: Incorporar mapas de datos avanzados de ESRI para análisis geoespaciales detallados.
- Mapa Azure: Utilizar datos geoespaciales de Azure para análisis en la nube con integración de datos en tiempo real.

# Buenas prácticas de visualización avanzada
- Máx. 6 tipos de visual por página para no saturar.
- Emplea 3‑4 colores corporativos y evita degradados fuertes.
- Usa títulos ≤ 40 caracteres; agrega subtítulos si hace falta contexto.
- Agrupa visuales relacionados con bordes o un fondo discreto.
- Revisa rendimiento: demasiados gráficos complejos ralentizan la carga.

# POBLACION Y MUESTRA
## Población 
EL CONJUNTO COMPLETO de elementos que nos interesan en un estudio.

RESULTados de la poblacion = Parametros.

## Muestra 
Subconjunto seleccionado de la poblacion.

Resultados de la muestra = Estadisticas.

una buena muestra tiene que tener 
- Aleatoriedad: Cada elemento tiene que tener la misma probabilidad de ser seleccionado.

- Representativa: cada elemento tiene la carcteristica principal para el estudio.

# Clasificacion de Datos
Tipos de datos:
- Categóricos: este tipo de datos nos ayuda a clasificar o agrupar información.

Graficos de barra o de sectore o anillos.

- Numéricos: 
    - Discretos : Pueden ser contados (numeros enteros). 
    Graficos Columnas o tablas.
    - Continuos : Los datos continuos pueden tomar cualquier valor dentro de un rango, incluyendo cifras decimales extremadamente.
    Graficos en lineas o histogramas.

# Clasificacion de niveles de medicion.
- Cuanlitativos: describir categorias.
    - Nominal:Estos datos se utilizan para categorizar información sin ningún orden intrínseco.

    - Ordinal: tienen un orden implícito.
    Esto significa que aunque no se pueden medir con precisión las diferencias entre categorías, sí se pueden clasificar de menor a mayor.

- Cuantitativos: Numero.
    - Intervalo:Estos datos permiten medir diferencias consistentes entre valores, pero no tienen un cero absoluto.
    no permite hacer comparaciones proporcionales.

    - Razón: sí tienen un ser absoluto.
    Esto significa que el cero representa realmente la ausencia total de la variable.

# Visualizacion de datos Categoricos.
- Tablas de frecuencia que nos van a ayudar a organizar categorías y sus
frecuencias de manera clara y estructurada.
- Gráficos de barras que son perfectos para comparar categorías entre sí
y visualizar qué elementos destacan.
- Gráficos de sectores o gráficos de pastel que son útiles para entender
las proporciones, los porcentajes de cada categoría en relación con el total.
- Diagrama de Pareto que combina gráficos de barras y curvas acumulativas para priorizar problemas o analizar eficiencia.
